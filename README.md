# Restaurant Data Analysis & Power BI Dashboard

## 📌 Project Overview

This project was completed as part of my Data Analysis Internship at Cognifyz Technologies.

The objective of this project was to analyze restaurant data, identify useful business insights, and create an interactive Power BI dashboard.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Power BI
- Data Cleaning
- Data Analysis
- Data Visualization

## 📊 Key Analysis

- Top 3 most popular cuisines
- Restaurant rating distribution
- Average votes and ratings
- Online delivery analysis
- Table booking analysis
- Price range analysis
- Business insights from restaurant data

## 📈 Dashboard

The Power BI dashboard provides an interactive view of restaurant data using charts, cards, and slicers.

## 💡 Key Insights

- Identified the most common cuisines among restaurants.
- Analyzed restaurant ratings and voting patterns.
- Compared online delivery and table booking availability across different price ranges.
- Created visual insights to support better understanding of restaurant business trends.

Through this project, I gained practical experience in:

- Data cleaning and preprocessing
- Exploratory data analysis
- Power BI dashboard development
- Data visualization
- Extracting business insights from data
